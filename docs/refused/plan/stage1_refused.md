# What was refused: Stage 1

What was weighed in `stage1.md` and refused, each with the condition that would bring it back.

## How the build is let into Bridge's release

Of `stage1.md`, *How the build is let into Bridge's release*.

Refused: a token of the owner's account, limited to reading Bridge, kept as one secret. It was
the one recommended: one secret, the least reach the service allows, and a run that fails
plainly the day it expires. Against it, it is a person's, and it lives for months. The
condition that brings it back is the app proving more to keep than it saves: its key lost or
renewed more than once a year.

Refused: Bridge made public, so that nothing is needed. It reverses the ruling that the three
are seen by the same people. The condition that brings it back is that ruling changing, and
the two secrets are then deleted.

Refused: Bridge's run writing its packages into this repository. Bridge would then hold what
writes here, and would know each backend by name, which is what leaving its tree undid. No
condition is seen that brings it back.

## What the pin states

Of `stage1.md`, *What the pin states*.

Refused: the hash of each package's statement, with the archive unpacked before anything is
held. It would survive a repeated run where the build gives the same files, which nothing
shows it does, and it opens an archive nothing has checked. The condition that brings it back
is runs repeated for one commit becoming usual.

Refused: the commit alone, the release being named for it. Whoever can put a file in a release
would then choose what every backend is built from. No condition is seen that brings it back
while a release's files can be replaced.

## What fetches

Of `stage1.md`, *What fetches*.

Refused: the program `gh`, called by the build. It is a few lines where ours are thirty, and
it finds a login on a machine with nothing set. Against it, it is a third thing to install
wherever this is built, and a token would arrive two ways. The condition that brings it back
is the service changing how an archive is asked for often enough that our lines cost more to
keep than the program to install.

Refused: our lines, with `gh` asked for a token where the variable is not set and the program
is there. It is behaviour that depends on what happens to be installed, which is meaning by
absence. No condition is seen that brings it back.
